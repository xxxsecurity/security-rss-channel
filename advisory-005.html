ADVISORY-005: Krytyczna podatnosc RCE w NetScaler ADC (CVE-2025-31337)

Zrodlo: example-security-blog.invalid | Data publikacji: 2026-11-20 | Autor: zespol badawczy Example Labs

Badacze ujawnili krytyczna podatnosc typu remote code execution w komponencie gateway produktu NetScaler ADC. Podatnosc CVE-2025-31337 (CVSS 9.8) pozwala nieuwierzytelnionemu atakujacemu na wykonanie dowolnego kodu poprzez spreparowane zadanie HTTP do endpointu /vpn/index. Producent opublikowal poprawke w wersji 14.1-29.72. Zaleca sie pilna aktualizacje oraz przeglad logow dostepu pod katem wskaznikow kompromitacji wymienionych w tabeli ponizej.
